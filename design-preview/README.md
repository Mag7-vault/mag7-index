# MAG7 frontend directions

This folder is a static presentation of eight visual concepts for the MAG7
frontend. It does not connect to wallets or contracts.

## View locally

Open `index.html` in a browser. For the most reliable result, serve this folder
with any static file server.

## Share

Send the complete `mag7-design-directions.zip` archive. The recipient should
extract it before opening `index.html` so the image assets remain available.

The same folder can be hosted unchanged on GitHub Pages, Netlify, Cloudflare
Pages, or Vercel.
